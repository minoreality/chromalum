# Color De Morgan circuit prototype

Theoryとは独立した論理回路の試作。「演算の結果を補色にする」回路と「各入力を補色にして双対の演算を取る」回路が同じ出力を持つことを示す。OR版、AND版を同じページに上下に並べる。二経路の図は [de-morgan](../de-morgan/README.md) に保存している。

- 「2入力／3入力」で色の入力数を切り替える。入力数と信号幅は別で、各入力は常に一つの3ビットGRB色を表す。
- 二入力の初期値は、OR版がG・R、AND版がM・C。前者はYの補色とM・CのANDがともにB、後者はBの補色とG・RのORがともにYになる。
- 三入力の初期値は、OR版がG・R・B、AND版がM・C・Y。前者はWの補色とM・C・YのANDがともにK、後者はKの補色とG・R・BのORがともにWになる。
- 各法則と各入力数の選択を独立に保持する。各入力は八状態から選べ、ラジオボタンは矢印キーでも切り替えられる。リセットは表示中の法則と入力数だけに適用する。
- AND・ORのゲート記号と独立したNOTゲートを使う。各ゲートはG・R・Bに対する三つの並列な1ビット演算を表し、入力線の斜線と「3」が3ビットバスを示す。
- 各信号に色名と3ビットを添える。三つの配置を切り替えて比較でき、入力の選択は切り替えても保つ。
  - 出力を中央：右側の回路を左右反転し、同じ結果を中央の一つの出力にまとめる。二つの計算の一致を示す図。
  - 入力を中央：左側の回路を左右反転し、中央の入力a・b（またはa・b・c）を共有して左右へ分岐する。両端にそれぞれの出力を置く。
  - 円環：共有する入力から二つの回路へ分かれ、一つの出力で合流する。入力と出力の両方を共有するので、二つの計算が一周して閉じる。入力aの線が両側とも最も外側を通り、入れ子になって交差しない。
- 向かい合わせの配置は、広い画面では左右、狭い画面では上下から中央へ接続する。反転・回転するのはゲートと配線で、文字は常に正立させる。SVGの座標幅を表示幅に合わせ、ゲートと文字を縮小しない。
- 円環は、広い画面では二つの経路図と同じく上から下へ流し、①を左、②を右に置く。狭い画面では左から右へ流し、①を上、②を下に置く。三入力の列を二つ並べると約520pxになり、320px表示の枠幅272pxに収まらないため。
- Theoryのコンポーネント、状態、スタイルを読み込まない。専用のHTML・スクリプト・スタイルだけを使う。
- 本番ビルドの入口には追加しない。アプリからのリンクも追加しない。

Vite起動後、`/chromalum/prototypes/de-morgan-circuit/` を開く。配置は `?layout=outputs`（既定）、`?layout=inputs`、`?layout=ring` で直接指定できる。入力数は既定が二つ、`?arity=3` で三つになる。組み合わせ例は `?layout=ring&arity=3#law-and`。各法則へのリンクは `#law-or` と `#law-and`。`?operation=and` もAND版の位置へ移動する。

```sh
npm run dev -- --host 127.0.0.1 --port 4173
npx tsc --noEmit -p prototypes/de-morgan-circuit/tsconfig.json
npx playwright test -c prototypes/de-morgan-circuit/playwright.config.ts --workers=1
```

ブラウザ検証は各配置・各法則の全64入力組（二入力）と全512入力組（三入力）、共有する入力／出力、反転方向、配置と入力数の切り替え時の選択の保持、入力とリセットの独立性、キーボード操作、320〜1186pxでの表示と文字の向き、円環の配線が交差しないこと、旧ANDリンクを対象とする。期待する原色集合は集合の所属から求め、画面実装のビット演算とは独立に確認する。
