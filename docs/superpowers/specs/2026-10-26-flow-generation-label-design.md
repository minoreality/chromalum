# Flowの世代数と編集状態

2026-10-26のユーザー注釈で指定された2点のみを追加する。

- スライダーのラベルを日本語「世代：{0} / {1}」、英語「Generation: {0} / {1}」にする。現在値と上限64を渡す。
- その隣に、t=0では「初期配置を編集」／「Edit initial pattern」、t>0では「結果を表示」／「View result」を表示する。
- 世代数はスライダーのラベル、状態は説明として関連付ける。状態を別の操作ボタンにはしない。
- 最大桁数の世代数と両方の状態文言に必要な領域を常に確保し、時間操作で高さ・位置を変えない。
- 広幅と狭幅、日本語と英語、MS Gothicで読み取りと配置を確認する。
- 色、文字サイズ、全体表示、計算キャッシュ、既存の描画・保存・規則・ボタンの動作は今回の対象外。

既存の49×49表示と64世代・周囲計算の変更に重ねて実装し、既存の未コミット変更を維持する。
状態を独立した行に置く案も検討したが、スライダーの説明として近接させるため同じ見出し行を使う。
