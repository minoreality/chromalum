# Flowの色の演算と関係

ユーザーは既存8規則を残したXOR系の整理、OR・AND・多数決・Hamming距離の反転、および性質を観察できる初期配置の追加を承認した。

- OR / AND は自分と上下左右の5セルに対するビットごとの和集合 / 共通部分。
- 多数決は同じ5セルで、各チャンネルが3セル以上で点灯していれば点灯。
- Hamming は上下左右のうち自分と1ビットだけ異なる色から差分マスクを受け、現在色に全マスクをXORする。同じ反転は偶数回で相殺。中心セルを近傍には数えない。
- 全規則は同期更新、半径1、黒の静止背景を保つ。49×49の表示窓・64世代・外側の計算・既存の保存形式と識別子を維持する。
- 選択欄を増やす案に対して、既存の規則選択欄をXOR・色の演算と関係・ライフ系のグループに分ける案を採用する。元のXORの名称と6通りの組み合わせを保ち、既存の操作を変更しない。
- 新規初期配置は ORの三原色の広がり、ANDの共通色の芯、多数決の穴と飛び点、Hammingの1ビット差と補色。名前で対応規則が分かるようにする。配置選択で更新規則を自動変更しない。
- 規則の短い説明を選択欄の下に表示し、全説明を同じグリッド位置に重ねて最大の高さを予約する。説明の切り替えで盤面や操作群を動かさない。
- Theoryのブール代数・反転マスク・Hamming距離を根拠にするが、新しい空間更新則をTheoryからの一意な帰結や物理的混色とは呼ばない。

## 初期配置の設計

ORは離れた三原色の小さな面を配置し、広がった領域がCMY・白へ重なる。ANDはM/Y、C/Y、M/Cの隣接する面の間に白い列を置き、共通するR/G/Bの芯が残る。多数決は三原色の面に小穴・突出・孤立点を付け、1世代で修復・除去される配置とする。Hammingは上にR/Y、下にR/Cの接する面を置き、1世代後の境界の違いを比べる。

## 検証

既存の固定参照例を維持し、OR/AND/多数決の全32局所ビット配置、Hammingの全64色対と偶数反転の相殺、黒い外側、世代64の表示窓を検証する。新規初期配置の観察点、保存と復元、選択欄の全項目、説明の読み上げ、描画状態の維持を確認する。日本語・英語と広幅・狭幅で配置と選択メニューを確認する。
