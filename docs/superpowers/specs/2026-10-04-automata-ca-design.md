# Automataへの既存セル・オートマトンの統合

## 目的と合意した範囲

既存のCHROMALUM CA Labの二次元機能を、CHROMALUM本体のReact画面として移植する。メインタブ名は日英ともに **Automata** とし、Musicの右側、メインタブの末尾に置く。初版は、二次元の配置編集と更新、本体に揃えたUI、操作状態の保存を提供する。

成功条件は、利用者がAutomata内のパレットで色を選び、盤面へ直接配置し、規則を選んで同じ盤面の変化を見られること。同じ初期配置・規則・時刻から既存版と同じ結果が出て、タブ切り替えと再読み込み後にも編集を続けられることを確認する。

操作は「盤面そのものが時間とともに変わる」に統一する。盤面は一つで、時刻0の初期配置編集と、その後の結果表示を同じ場所で扱う。二次元の盤面はピクセルアートと同じ空間の配置として編集できることを重視する。

初版の表示は8色に固定する。盤面種別、G／R／B表示、列・行の数値入力、配置色のプルダウン、「このセルに色を置く」ボタンは設けない。一次元の時間履歴・Rule 90／150・独立と結合の比較、チャンネルごとの観察は既存の単体CA Labで扱う。

CHROMALUMで描いた絵をAutomataの初期配置に使う機能は、ユーザーの判断により後の追加候補として保留する。初版の初期配置は、既存の12プリセットと盤面の直接編集から作る。

Boolean Network、Sourceへの模様送付、自動再生も今回の実装範囲に含めない。これらは統合版を操作したあとで検討する。

## 状態空間と更新規則

各セルは `A = {0,1}³` の一状態であり、GRB順の3ビットを0〜7で符号化する。色とコードは `K=000, B=001, R=010, M=011, G=100, C=101, Y=110, W=111` とする。計算・初期配置編集・8色表示は、この離散状態に対して行う。

GRB Binary Toneの順位とビットの場所、知覚的明るさ、純色相環上の連続色候補は区別する。Hex／Glazeの色候補や連続RGB値はCAの演算に入力しない。XORはビット反転の合成と相殺であり、物理的な混色の説明には使わない。

CAの規則は、この状態空間に追加する選択である。規則がCHROMALUMの代数から一意に導かれる、またはCA自体が本プロジェクトの新規発明であるという説明は加えない。研究ノートにある数学的主張と既存Theoryの文章は変更しない。

### 二次元の操作と規則

- 49×49セル、時刻 `t=0..20`。範囲外はK。全セルを同時に更新する。
- XOR規則は、十字4セル、十字＋中央5セル、斜め4セル、斜め＋中央5セル、周囲8セル、周囲＋中央9セルの6種類。
- ライフゲームはチャンネルごとにB3/S23を適用する。
- 「ペルシャ絨毯」は既存UIの名称を保ち、チャンネルごとにB234/Sなしを適用する。現在0のセルは周囲の1が2・3・4個のときに1となり、現在1のセルは次に0となる。
- 初期配置は `rosette, diamond, corolla, luminous, clock, phase-clock, pulse, fireworks, weave, rgb, white, black` の12種類。名称と配置を引き継ぐ。
- プリセット変更は選択座標を中央に戻し、時刻0にする。選択した規則と配置色は保つ。元の一部プリセットで使われていた時刻7への移動は、すぐ編集できる一画面の入口に合わせて変更する。
- 一つの盤面を常に8色で表示する。時刻0は初期配置、時刻1〜20は初期配置から計算した結果を表示する。
- 「初期配置に戻る」は時刻を0にする。初期配置・規則・配置色を保ち、プリセットから再生成しない。時刻0では無効にする。
- 「1ステップ進む」は時刻を1増やし、20で無効になる。
- 時間スライダーで時刻0〜20を直接選べる。時刻を戻しても初期配置は保持する。

### パレットと盤面の直接操作

- 配置色は常時表示する8個のパレットボタンから選ぶ。順序は `K, B, R, M, G, C, Y, W`。広い画面では8色を一列、狭い画面では4色ずつ二列にする。色面に記号を添え、選択色は枠と色名・GRBコードでも示す。黒Kはセルを0に戻すためにも使う。
- パレットはどの時刻でも操作できる。色の変更だけでは初期配置、規則、時刻を変えない。
- 時刻0のタップ／主ボタンのクリックは、セルを選択すると同時にパレットの色を置く。
- 時刻0のドラッグは、通過したセルを押し始めたときの色で連続して塗る。速い移動でイベント間にセルが抜けないよう、連続したセル座標間を整数格子上の線で補間する。選択セルは最後に盤面内で触れたセルにする。
- 時刻1〜20のタップ／クリック／ドラッグは、選択セルの変更と情報の読み取りを行う。初期配置と計算結果は書き換えない。編集する際は「初期配置に戻る」を使う。
- 列・行の数値入力と独立した配置ボタンは置かない。選択座標は読み取り欄へ表示する。
- Pointer Eventsでマウス・タッチ・ペンの単一ポインターを扱う。非主ボタンと追加の指は描画を始めない。盤面内で始めた操作はポインターを捕捉し、盤面外ではセルを書き換えない。盤面外へ出て再び入った場合は、再入場したセルから描画を再開し、外へ出る前のセルとの補間線を引かない。
- 盤面内のタッチドラッグは編集／読み取りに使い、盤面外ではページをスクロールできる。
- 指や主ボタンを離す、`pointercancel`、`lostpointercapture`、ウィンドウのフォーカス喪失、タブの非表示で操作を終了する。規則・プリセット・時刻・配置色の変更や盤面寸法の変更でも操作を終了する。既に置いた色は保持し、後のポインター移動で描画が再開しないようにする。
- ドラッグ中は盤面を随時更新し、保存は操作の終了／中断時にまとめる。
- キーボードでは盤面にフォーカスを置き、矢印キーで選択セルを移動し、時刻0のEnter／Spaceでパレットの色を置ける。範囲外へは移動しない。パレットは通常のボタンとして操作でき、選択状態を `aria-pressed` で伝える。

### 初回の既定値

初回に保存状態がなければ、規則は十字4セル、初期配置は三色の対称花 `rosette`、時刻0、選択座標は(24,24)、配置色はGとする。最初の画面からパレットと盤面で編集できるよう、元の時刻7から変更する。

## 本体への接続と責務

タブIDとURLハッシュは `automata` とする。`src/tabs.ts` の `MAIN_TABS` の末尾に追加し、順序は `Gallery, Hex, Source, Glaze, Map, Theory, Music, Automata` とする。既存のタブIDによるタイトル・保存・履歴移動・キーボード操作に接続する。旧タブ番号の互換表は固定された旧順序を保ち、新しいタブ順から再生成しない。

画面は初回に開いたときに遅延読み込みし、その後はタブを隠しても状態を保持する。非表示中はCanvasの計測と描画を停止し、表示されたときに現在のコンテナー幅で描き直す。状態保存が使えない場合も、同じアプリ起動中のタブ切り替えでは編集を保持する。

責務は次の単位に分ける。ファイル名は実装計画で固定するが、境界はこの設計に従う。

| 単位           | 責務・入出力                                                                               |
| :------------- | :----------------------------------------------------------------------------------------- |
| CAモデル       | 初期配置、規則、時刻から盤面を返す純粋関数。入力を書き換えず、DOMと保存先に依存しない      |
| 初期配置データ | プリセットIDと固定寸法から0〜7の配置を生成する。表示文言は翻訳側に置く                     |
| 状態と保存     | 二次元の状態、操作による更新、保存値の検証と復元を担当する                                 |
| Canvas描画     | 状態データと描画寸法から描画し、ポインターの座標をセル座標へ変換する                       |
| 盤面操作       | ポインターの所有、連続描画、操作の終了、キーボードによる選択と配置を担当する               |
| AutomataPanel  | 見出し、保存状態の通知、規則とプリセットの入力、パレット、時刻、盤面、読み取り欄をまとめる |

初期配置・規則・時刻の変更で計算を更新する。配置色・選択セルだけの変更では、同じ計算結果を再利用する。結果の盤面は保存値に含めず、初期配置・規則・時刻から再計算する。

新しい依存パッケージ、別HTMLエントリー、バックエンドは追加しない。通常の本体ビルドに含め、既存のプロトタイプ用ビルド設定は使わない。

## 保存と失敗時の振る舞い

保存先はAutomata専用の `localStorage` キー `chromalum-automata-state-v1` とし、Source／GlazeのIndexedDB保存と分ける。ここでのv1は内部データ形式の識別子であり、製品のリリース番号ではない。

保存内容は、初期配置、プリセット、規則、時刻、選択座標、配置色。保存データには形式の識別値を含める。表示方法と操作中のポインター情報は保存しない。

復元時は、許可した文字列、整数範囲、配列の長さ、各セルが0〜7であることを検証する。不正な項目は、その項目または初期配置だけを既定値へ戻し、他の妥当な設定は保つ。未知の形式やJSONの破損は初回の既定値に戻す。

保存を拒否された場合も画面は動作し、メモリー内の状態を保持する。保存失敗が実際に起きたときは、再読み込み後の復元ができないことを非モーダルの通知で伝える。

移植元の `window.openai.widgetState` と本体の保存先は別である。本体は新しいキーから復元し、既存プレビューの保存状態はそのまま残す。この初版に外部プレビューからの自動取り込み機能は設けない。

## 表示・操作・アクセシビリティ

新規スタイルはすべて `src/styles/global.css` に置き、既存の色・文字・間隔のトークンを使う。見出しはAutomata、その下にCellular Automatonの操作画面を置く。UIと読み取り用ラベルを日英に対応させ、数式・GRB・更新規則の表記を保つ。

幅に応じた配置はコンテナークエリーと `clamp()`／`cqw` を使う。一つの正方形の盤面に表示幅を使い、操作部と8色パレットは狭い画面でも操作できるように配置する。8タブのナビゲーションも最小幅で検証し、ラベルを切らず、折り返した場合の高さを選択中のタブによらず一定にする。

時刻0と時刻1〜20で同じCanvasと寸法を使い、ステップを進めても操作部・Canvas・パレット・読み取り欄の位置を保つ。「初期配置を編集」と「現在の配置」の状態表示は、両方の文言を同じグリッドセルに置き、非表示の文言も高さを確保する。時刻だけが変わる操作ではCanvasを作り直さない。サイズ変更と表示再開は `ResizeObserver` で再計測する。Canvasのデバイスピクセル比の調整は、CSS上の描画寸法と独立させる。

Canvasには意味のあるラベルとキーボード操作の説明を付け、選択した座標・時刻・色・GRBコードをDOMの読み取り欄にも表示する。初期配置の同じセルの値も読み取り欄に表示して、別の盤面を描かずに比較できるようにする。パレットと盤面のキーボード操作で配置編集を完結できる。読み取り欄の重要な変更は `aria-live="polite"` で伝え、ドラッグ中の読み上げは操作の終了時にまとめる。

グローバルな描画ショートカットがAutomataの入力を奪ったり、Sourceの画像を変更したりしないことを確認する。タブの矢印・Home・End、ハッシュによる直接表示、ブラウザーの戻る／進むを既存仕様に合わせる。

この初版は明示的なステップ操作を使う。選択時刻の更新にモーションを追加しない。

## 検証と受け入れ条件

### 計算と保存

- 全8規則の結果を、チャンネル別の二値更新と突き合わせる。境界外K、同期更新、入力の不変性を検証する。
- 各初期配置と全8規則を、移植元から固定した期待値と比較する。ライフゲームの既知の固定点と周期、外側Kの小さな盤面も使う。
- 保存と復元の往復、不正な保存項目、配列長の不一致、保存拒否を確認する。不正な項目以外の妥当な設定は保つことを検証する。
- 単一セルの配置、黒での消去、連続描画の補間、盤面外の操作を確認する。水平・垂直・斜めの速い移動で、両端の間に未描画の隙間を残さないことを検証する。
- 時刻1〜20での選択は初期配置を変更しない。「初期配置に戻る」と時刻の往復でも初期配置を失わない。配置色の変更だけでは再計算や時刻の変更を起こさない。
- 中断・タブ移動・時刻変更・規則変更でポインターの所有が残らず、中断までの編集が保存されることを検証する。追加の指の開始・終了で、操作中の主ポインターを取り違えないことも確認する。

### 本体とブラウザー

- `#automata` で直接開ける。タイトルは `CHROMALUM - Automata`。日英ともタブ名はAutomata。
- 日英切り替えで操作状態を保ち、全ての新しい翻訳キーとラベルを確認する。
- 別タブへ移動して戻る操作と、再読み込みの両方で状態を復元する。Source／Glazeの保存内容に変更がないことも確認する。
- Source／Glazeの絵を変更しても、Automataで作った初期配置は保持する。本体の絵を初期配置へ取り込む選択肢や自動同期はこの初版には設けない。
- 盤面は一つ、パレットは常時表示の8ボタンであり、列・行入力、配置色のプルダウン、「このセルに色を置く」ボタン、チャンネル表示の切り替えがないことを確認する。
- マウスのクリック／ドラッグ、タッチのタップ／ドラッグ、キーボードで色の選択と初期配置編集を行える。盤面外ではページをスクロールできる。中断後や別タブでのポインター移動は描画しない。
- 「1ステップ進む」の前後と、時刻0への復帰で、操作部、Canvas、パレット、読み取り欄の矩形を測定する。時刻のみの更新による位置・寸法の変化を許容しない。
- 広い画面と320〜390px程度の縦長画面で、横にはみ出し・文字の重なり・操作対象の重なりを確認する。MS Gothicなど幅広の字形でもラベルが収まることを検証する。
- タブ順は `Gallery, Hex, Source, Glaze, Map, Theory, Music, Automata`。タブのEndキーはAutomata、HomeキーはGalleryへ移動する。先頭と末尾の矢印移動は既存仕様どおり循環する。
- キーボードだけでタブ移動、規則選択、初期配置編集、ステップ操作ができる。末尾へのタブ追加に影響する既存ユニットテスト・e2eとアクセシビリティの期待値を更新する。
- 新しい計算テストと関連e2eを通した後、`npm run verify`、`npm run test:e2e -- --workers=2`、`npm run test:pwa` を実行する。e2eの失敗は対象を `--workers=1` で再確認する。PRのカバレッジゲートは別途 `npm run test:coverage` で確認する。
